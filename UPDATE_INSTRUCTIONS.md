# NPC Depth Lab updates

Research date: 20 October 2026. This is an initial researched pool, not an exhaustive NPC census.

Canonical appearances provider is RuckMob. Use competition rows in Career by season, not lagging overview cards. Do not import appearance numbers from NZ Rugby Tracker, It's Rugby or club biographies. Other sources may identify incomplete historical coverage but must not replace the canonical count. A full career total requires complete competition coverage, otherwise preserve null and give the provider recorded count explicitly in appearanceNote. Season game counts and full box score sample sizes can differ; preserve both definitions. Unknown is not zero.

Use official union or franchise announcements for commitments. Search all NZ and overseas Super Rugby teams. Exclude all capped All Blacks and known 2027 main squad or WTG contracts. Preserve removed players and their evidence in excluded. Asterisks mark 2026 main squad or WTG players with unresolved 2027 status. Overseas clubs or sevens commitments are flagged, not automatically called available. A current injury needs a dated current report. No report is not proof of fitness.

Read /api/board before any update and preserve its complete schema and existing profiles. Write the full revised JSON to /api/update with service access acquired fresh using Sites get_site for this project; send its token only as OAI-Sites-Authorization: Bearer token to this Site. Do not persist credentials. Alternatively use the connected Site tool update_npc_board. The owner private platform boundary protects the shared writer. Never change audience to make writes work. Read /api/board afterward and verify changes. Each save creates an R2 history snapshot. Routine dataset updates require no source deployment.

RuckMob metrics must explicitly be NPC 2026. A page can have older season metric sections despite a current career row. Do not import those. Keep raw stats separate from provider percentiles. percentiles has Attack, Defence, Discipline objects. Front row rated inputs: Attack metres per80 and carries per80; Defence tackles per80, tackle success and turnovers won per80; Discipline penalties conceded per80. Backs: Attack metres per80, clean breaks per80, defenders beaten percarry, try involvements per80; Defence tackles per80, tackle success; Discipline penalties conceded per80, turnovers lost per10 touches. Source peer group and minute sample must be preserved. Rates and source percentiles are descriptive, not verified quality rankings. Keep missing fields null. Do not manufacture scores or set piece metrics.

AGI v1.0 is calculated in the UI from equal within domain means and fixed positional domain weights. Props 25/55/20, hooker30/50/20, locks25/55/20, loose forwards35/50/15, halves55/25/20, centres50/35/15, wings65/25/10, fullback60/25/15. All three domains and at least160 metric sample minutes required. Small sample160 to399, established400+. Every score remains a provisional analyst screening index. Source percentiles are position group comparisons, not computed from only this selected list. AGI is not an overall percentile and not a literal average of match ratings. Avoid cross position ranking claims. The UI key explains score bands and limitations.
